# Smart Environmental Monitor using ESP32

## Project Overview
The Smart Environmental Monitor is an embedded systems project developed using an ESP32 microcontroller and a DHT22 sensor to measure temperature and humidity. The sensor readings are displayed on the Serial Monitor and an I2C LCD.

## Features
- Real-time temperature monitoring
- Humidity measurement
- Sensor readings updated every 2 seconds
- Serial Monitor output
- I2C LCD display
- Circuit simulation using Wokwi

## Components Used
- ESP32 development board
- DHT22 temperature and humidity sensor
- 16x2 I2C LCD display
- Connecting wires

## Software and Technologies
- Arduino C++
- Wokwi Simulator

## Working Principle
The DHT22 sensor measures the surrounding temperature and humidity. The ESP32 reads the sensor values and displays them on the Serial Monitor and LCD every two seconds.
